Binárna a hexadecimálna číselná sústava

1Dvojková (binárna) sústava

Základ 2, cifry 0 a 1; jedna cifra = bit (binary digit). Elektronika spoľahlivo rozlíši dva stavy (prúd tečie / netečie).

2⁷2⁶2⁵2⁴2³2²2¹2⁰
1286432168421

Počítanie: 0, 1, 10, 11, 100, 101, 110, 111, 1000… Najpravejší bit = najnižší (najmenšia váha).

2Koľko sa zmestí do n bitov

n bitov = 2ⁿ hodnôt, čísla 0 až 2ⁿ − 1.

1 bajt = 8 bitov = 256 hodnôt (0 až 255); preto zložka farby 0 – 255.

IPv4: 32 bitov ≈ 4,3 miliardy adries, nestačí → IPv6 so 128 bitmi.

3Sčítanie v dvojkovej sústave

0 + 00
0 + 11
1 + 110 (píšem 0, prenášam 1)
1 + 1 + 111

Sčítavame po stĺpcoch sprava doľava. Ak sa výsledok nezmestí do počtu bitov, nastane pretečenie (overflow).

4Šestnástková (hexadecimálna) sústava

Základ 16, cifry 0 – 9 a A = 10, B = 11, C = 12, D = 13, E = 14, F = 15. Počítame … 9, A … F, 10 … 1F, 20 … FF, 100.

16 = 2⁴: 1 šestnástková cifra = 4 bity (nibble), 1 bajt = 2 cifry (00 – FF).

Zápis: 2F16, 0x2F, #2F, 2Fh.

farby#FF8800
MAC00:1A:2B:3C:4D:5E
UnicodeU+00E1 = á
IPv62001:db8::1
adresy v pamäti0x7FFE0000
chybové kódy0x80070005
💡 Vedel si? Bajt sa po anglicky píše byte (podobne ako bite = sústo) a polovica bajtu, 4 bity, sa volá nibble = „uhryznutie“.

📌 Zapamätaj si

  • Váhy dvojkovej: 1, 2, 4, 8, 16, 32, 64, 128.
  • n bitov = 2ⁿ hodnôt; bajt 0 – 255.
  • 1 + 1 = 10, pozor na pretečenie.
  • 1 hexa cifra = 4 bity, bajt = 2 cifry.
