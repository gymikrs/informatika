Funkcie, návratová hodnota funkcie

1Definícia a volanie funkcie

def pozdrav(meno): # definícia: meno funkcie a parameter print('Ahoj,', meno) pozdrav('Ema') # volanie: argument 'Ema' pozdrav('Tomáš')

Funkciu definujeme kľúčovým slovom def, menom, zátvorkami s parametrami a dvojbodkou. Telo je odsadené. Funkcia sa vykoná až pri volaní. Parametre môžu mať predvolenú hodnotu: def mocnina(x, n=2):. Premenné vytvorené vo funkcii sú lokálne: mimo funkcie neexistujú a nezmenia globálnu premennú s rovnakým menom.

2Návratová hodnota

Príkaz return hodnota funkciu ukončí a vráti výsledok tam, odkiaľ bola zavolaná. S výsledkom môžeme ďalej počítať, uložiť ho do premennej alebo ho vypísať. print iba zobrazuje, return vracia. Funkcia bez return vracia None. Funkcia môže vrátiť aj viac hodnôt naraz (ako n-ticu): return mn, mx.

def obsah(a, b): return a * b s = obsah(3, 4) + obsah(2, 5) # 12 + 10 print(s)

3Dôležité vzory v programoch

  • Najprv definície funkcií, potom hlavný program.
  • Funkcia má robiť jednu vec.
  • Výsledok funkcie ulož do premennej alebo ho hneď použi.

4Funkcie v praxi

Funkciu napíš vtedy, keď sa niečo opakuje alebo keď chceš program rozdeliť na prehľadné časti. Dobrá funkcia dostane údaje cez parametre a výsledok vráti príkazom return. Tak sa dá použiť v ďalšom výpočte aj vo výpise. Premenné vo funkcii sú lokálne: zmena parametra vo vnútri funkcie nezmení premennú mimo nej. Viac hodnôt vrátiš naraz ako n-ticu: return a, b.

💡 Vedel si? Funkcie ako print, len či input sú tiež funkcie – niekto ich raz definoval príkazom podobným def.

📌 Zapamätaj si

  • Funkciu definujeme def meno(parametre): a telo odsadíme.
  • Telo sa vykoná až pri volaní meno(argumenty).
  • return vráti hodnotu a ukončí funkciu.
  • Bez return funkcia vráti None.
  • Najprv definície funkcií, potom hlavný program.
  • Funkcia má robiť jednu vec.
  • Funkcia nič nerobí? Chýba volanie.
