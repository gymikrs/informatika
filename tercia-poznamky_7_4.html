Na verejnú stránku nedávaj osobné údaje.

2Tvorba stránky

  • Kostra: DOCTYPE, html lang, meta charset, title.
  • Nadpis <h1>, časti <h2>, odseky <p>.
  • Zoznam <ul>/<ol>, odkaz <a href>, obrázok <img alt>.
  • Kontrolovať môžeš viackrát, prácu si priebežne sťahuj.

4Odovzdanie

  • Hlavná stránka webu sa volá index.html.
  • Súbor otvoríš dvojklikom v prehliadači.
  • Obrázky ulož do priečinka so stránkou, odkazuj relatívne.
  • Zadarmo zverejníš napríklad na GitHub Pages.

5Kontrola pred odovzdaním

  • Hlavný nadpis <h1>, časť <h2>.
  • Zdroj: odkaz <a href>.
  • Fotka: <img src alt>.
  • Zoznam <ul>, údaje <table>.
  • Najčastejšia chyba: neukončená párová značka.
