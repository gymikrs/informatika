Python – úvod a inštalácia

1Čo je Python

Python vytvoril Holanďan Guido van Rossum, prvá verzia vyšla v roku 1991. Je zadarmo a open source, beží vo Windows, macOS aj Linuxe.

Je interpretovaný: interpreter vykonáva program riadok po riadku. Má čitateľnú syntax (bloky sa vyznačujú odsadením) a tisíce knižníc.

OblasťNa čo
umelá inteligenciastrojové učenie, rozpoznávanie obrázkov a reči
analýza dát a vedaspracovanie meraní, grafy, výpočty
web a automatizáciaserverová časť webov, skripty
hry a výučbajednoduché hry, prvý jazyk

2Inštalácia

KrokČo urobíš
1na python.org (Downloads) stiahni inštalátor
2vo Windows zaškrtni Add python.exe to PATH
3klikni na Install Now
4over príkazom python --version

S Pythonom sa nainštaluje IDLE a správca balíkov pip (pip install názov). PATH = zoznam priečinkov, v ktorých systém hľadá programy. Iné možnosti: Thonny, online Replit.

3Prostredie IDLE

OknoNa čo slúži
Shell (výzva >>>)interaktívny: príkaz sa vykoná hneď, na skúšanie
Editor (File › New File)celý program, uložíš ako .py a spustíš Run › Run Module (F5)

Výstup programu z editora sa zobrazí v okne Shell.

4Prvé príkazy v Shelli

Shell funguje ako kalkulačka: napíšeš výraz, Enter a hneď vidíš výsledok.

OperátorVýznam
+ - * /sčítanie, odčítanie, násobenie, delenie
**mocnina
//celočíselné delenie
%zvyšok po delení

/ dá vždy desatinné číslo (9 / 3 = 3.0). Premenná si zapamätá hodnotu: vek = 16, potom vek + 1.

5Prvý program

PríkazČo robí
print(…)vypisuje; hodnoty oddeľuj čiarkou
input(text)vypíše otázku, počká a vráti odpoveď ako reťazec
int(input(…))prevedie odpoveď na číslo
'a' + 'b'spojí reťazce

Reťazec a číslo sa nedajú spojiť plusom → TypeError.

6Prvé chyby

ChybaČo znamená
SyntaxErrorzlý zápis (úvodzovka, zátvorka, dvojbodka)
NameErrorneznáme meno (preklep, veľké písmeno, nevytvorená premenná)
TypeErrornesprávne typy, napr. reťazec z input() a číslo

Hlásenie čítaj odspodu: typ chyby, potom číslo riadka. Oprav jednu vec a spusti znova.
