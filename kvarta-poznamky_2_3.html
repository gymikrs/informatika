Programovací režim

1Príkazový a programovací režim

⌨️ Príkazový režim (Shell)príkaz napíšeš za >>>, stlačíš Enter a hneď sa vykoná; hodí sa na skúšanie
📝 Programovací režim (editor)napíšeš celý program, uložíš ho a spustíš klávesom F5; príkazy sa vykonajú všetky, zhora nadol

V programovacom režime pracuješ s tromi oknami: editor s programom, okno s korytnačkou a Shell, kde Python píše správy a chyby.

from turtle import * fd(100) rt(90)

2Prvý program

Program je postupnosť príkazov uložená v súbore s príponou .py. Píšeme ho v editore: File → New File.

SkratkaČo urobíMenu
Ctrl + Nnový programFile → New File
Ctrl + SuložiťFile → Save
F5spustiťRun → Run Module
Ctrl + Ootvoriť uloženýFile → Open

Program musí začínať riadkom from turtle import *. Hviezdičky v názve okna = neuložené zmeny.

3Ukladanie a názvy programov

💾 Uloženie: Ctrl + S alebo File → Save; prvýkrát IDLE vypýta názov.

📂 Otvorenie: pravým tlačidlom na súbor → Edit with IDLE, alebo v IDLE File → Open.

4Písmená veľkej abecedy

Zložitejšie obrázky skladáme z rovných čiar a otočení. Hranaté písmená sú na to ideálne.

Korytnačka smie prejsť po tej istej čiare aj viackrát, napríklad späť príkazom bk().

Pred písaním programu si písmeno načrtni: kde začneš, v akom poradí pôjdeš a aké dlhé sú čiary.

5Digitálne číslice

Číslice na digitálnych hodinách sa skladajú zo 7 úsečiek (segmentov). Naša číslica je 50 široká a 100 vysoká.

Číslicu začni kresliť v ľavom dolnom rohu a na konci vráť korytnačku späť do ľavého dolného rohu. Vďaka tomu sa dajú číslice ľahko kresliť vedľa seba.

💡 Vedel si? Okno Shell sa odborne volá aj REPL, z anglického Read, Eval, Print, Loop: prečítaj príkaz, vyhodnoť ho, vypíš výsledok a opakuj.

📌 Zapamätaj si

  • Shell: príkaz sa vykoná hneď po Enter; editor: celý program spustíš F5.
  • Program = súbor .py; Ctrl + N nový, Ctrl + S uložiť, F5 spustiť, Ctrl + O otvoriť.
  • Program s korytnačkou začína riadkom from turtle import *.
  • Názov: číslo listu + výstižné meno, bez medzier, diakritiky a mien modulov.
  • Obrázok si najprv načrtni; korytnačka smie ísť po čiare viackrát.
