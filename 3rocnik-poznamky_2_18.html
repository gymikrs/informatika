Polia, indexovanie

1Indexy a zmena prvkov

Prvok poľa (zoznamu) vyberieme indexom v hranatých zátvorkách: z[0] je prvý, z[len(z) - 1] alebo z[-1] posledný. Platné indexy sú 0 až len(z) − 1, inak IndexError. Prvok môžeme zmeniť: z[1] = 99. Výmena dvoch prvkov: z[i], z[j] = z[j], z[i]. Index hodnoty zistíme z.index(x).

z = [7, 3, 9, 1] # 0 1 2 3 (indexy) # -4 -3 -2 -1

2Rezy a dvojrozmerné pole

Rez z[od:do:krok] vytvorí nový zoznam: z[1:3], z[:2], z[::2], z[::-1] (obrátený). z[:] vytvorí kópiu. Pozor: b = a kópiu nevytvorí, obe mená ukazujú na ten istý zoznam.

Dvojrozmerné pole (tabuľka, matica) je zoznam zoznamov: m = [[1, 2, 3], [4, 5, 6]]; prvok v riadku r a stĺpci s je m[r][s].

3Algoritmy s indexmi

  • Index maxima: začni imax = 0, porovnávaj z[i] > z[imax].
  • Prechádzaj indexy cez range(len(z)).
  • Zmena prvkov v cykle iba cez index, nie cez for x in z.
  • Hľadanie: prejdi zoznam a zapamätaj si index nájdeného prvku.

4Indexy v praxi

Pri práci s indexmi si vždy over rozsah: platné indexy sú 0 až len(z) - 1, záporné počítajú od konca. Ak chceš prvky meniť, prechádzaj zoznam cez indexy for i in range(len(z)), lebo for x in z mení iba kópiu hodnoty v premennej x. Rez z[od:do] vytvorí nový zoznam a koniec do nie je zahrnutý. Pozor na b = a: obe mená ukazujú na ten istý zoznam.

💡 Vedel si? V jazyku Lua alebo Matlab sa indexuje od 1. Python, C aj Java začínajú od 0.

📌 Zapamätaj si

  • Platné indexy sú 0 až len(z) - 1.
  • Rez z[od:do] – prvok do už nepatrí.
  • Index maxima: začni imax = 0, porovnávaj z[i] > z[imax].
  • Over hranice: 0 a len(z) - 1.
  • Záporné indexy počítajú od konca: z[-1] je posledný prvok.
  • Rez s krokom z[od:do:krok]; z[::-1] otočí zoznam.
  • Prechádzaj indexy cez range(len(z)).
