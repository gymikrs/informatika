Inštalácia a nastavenie Pythonu

1Čo je Python

Python je programovací jazyk. V programovacom jazyku píšeme príkazy, ktoré počítač vykoná. Python sa dá čítať skoro ako angličtina.

Kto a kedyGuido van Rossum, od roku 1989
Cenavoľne stiahnuteľný, zadarmo
Školyuniverzity, napr. FMFI UK v Bratislave, Masarykova univerzita v Brne
FirmyGoogle, YouTube, Dropbox, Mozilla…

My budeme v Pythone kresliť pomocou korytnačky.

2Stiahnutie a inštalácia

Python stiahneš zadarmo z oficiálnej stránky python.org/downloads. Spolu s ním sa nainštaluje aj IDLE, prostredie na programovanie.

V inštalátore pred Install Now zaškrtni Add python.exe to PATH. IDLE potom nájdeš v ponuke Štart.

PATH je zoznam priečinkov, v ktorých Windows hľadá programy.

🏫 V škole je Python nainštalovaný. Doma inštaluj iba s dovolením rodičov a vždy iba z python.org.

3IDLE a okno Shell

Po spustení IDLE sa otvorí okno Shell. Znaky >>> znamenajú: „Python čaká na tvoj príkaz.“

Napíšeš príkaz, stlačíš Enter a Python ho hneď vykoná = príkazový režim.

>>>výzva: Python čaká
čierny textto, čo si napísal ty
modrý textodpoveď Pythonu
červený textchyba

Šípkou ↑ vrátiš predchádzajúci príkaz.

Python píše desatinnú bodku (3.5), nie čiarku. Delenie / dá vždy desatinné číslo.

Poradie ako v matematike: zátvorky, potom násobenie a delenie, nakoniec sčítanie a odčítanie.

5Detektív chýb

Keď Python príkazu nerozumie, vypíše červenú chybovú správu. Často sa začína slovom Traceback. Najdôležitejší je jej posledný riadok.

SyntaxErrorzlý zápis, Python nerozumie príkazu
NameErrorPython nepozná napísané meno, často je to preklep

Python rozlišuje veľké a malé písmená. Hľadaniu a oprave chýb hovoríme ladenie.

6Nastavenie IDLE

🔠 Väčšie písmokarta Fonts: Size 14 a zaškrtnúť Bold
💾 Bez otázky na uloženiekarta General: At Start of Run (F5) → No Prompt

Nastavenia nájdeš v menu Options → Configure IDLE. Zmeny sa prejavia po kliknutí na Ok alebo Apply.
