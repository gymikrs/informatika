Numerické dáta a operácie

1Typy int a float

TypČo obsahujePríklady
intcelé čísla, ľubovoľne veľké7, -120, 2 ** 100
floatdesatinné čísla s obmedzenou presnosťou3.14, 7.0, 1e6

Desatinnú časť oddeľujeme bodkou. Typ zistíš funkciou type(). Bežné delenie / dá vždy float.

Mnohé desatinné čísla sa v dvojkovej sústave nedajú zapísať presne, preto vznikajú drobné chyby (0.1 + 0.2).

💡 Vedel si? Typ float zaberá v pamäti 64 bitov a pamätá si asi 15 – 17 platných číslic. Väčšie číslo ako asi 1,8 · 10³⁰⁸ Python zapíše ako inf (nekonečno).

📌 Zapamätaj si

  • int = celé (ľubovoľne veľké), float = desatinné s bodkou; type() zistí typ.
  • Operátory + − * / // % **; / dá vždy float.
  • Priorita: zátvorky → ** (sprava) → * / // % → + −; x += 5.
  • // zaokrúhľuje nadol aj pri záporných; round pri polovici k párnemu.
  • abs, round, int, float, min, max; import math → sqrt, pi, floor, ceil.
