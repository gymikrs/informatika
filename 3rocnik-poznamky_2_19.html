Podmienky

1If, elif, else

if body >= 90: znamka = 1 elif body >= 75: znamka = 2 elif body >= 50: znamka = 3 else: znamka = 5

Za if nasleduje podmienka a dvojbodka, príkazy vetvy sú odsadené. elif (else if) overí ďalšiu podmienku, iba ak predchádzajúce neplatili. else sa vykoná, keď neplatí žiadna. Vykoná sa najviac jedna vetva. elif ani else nie sú povinné.

2Zložené a vnorené podmienky

Podmienky spájame operátormi and, or, not: if vek >= 15 and vek <= 18: (alebo skrátene 15 <= vek <= 18). Podmienku môžeme vnoriť do inej vetvy, odsadenie je potom väčšie. Často sa dá vnorená podmienka nahradiť zloženou, program je potom prehľadnejší.

if n > 0: if n % 2 == 0: print('kladné párne') else: print('kladné nepárne') else: print('nie je kladné')

3Dôležité vzory v programoch

  • Pri hraniciach postupuj od najprísnejšej podmienky.
  • Párne číslo: n % 2 == 0.
  • Priestupný rok: r % 4 == 0 and r % 100 != 0 or r % 400 == 0.
  • Otestuj aj hraničné hodnoty.

4Rozhodovanie

Pri rozhodovaní najprv zisti, koľko možností program rozlišuje: dve = if a else, viac = if, elif, …, else. Podmienky v elif píš od najprísnejšej, lebo sa vykoná iba prvá splnená vetva. Dva samostatné if sa vyhodnotia nezávisle, preto môžu vypísať aj dve správy. Deliteľnosť zisťuješ zvyškom n % d == 0. Prázdny reťazec, 0 a prázdny zoznam sa v podmienke správajú ako False.

📌 Zapamätaj si

  • if podmienka: – telo sa vykoná, iba ak podmienka platí.
  • elif skúša ďalšiu podmienku, else zachytí všetko ostatné.
  • and – musia platiť obe podmienky.
  • or – stačí, aby platila jedna.
  • Pri hraniciach postupuj od najprísnejšej podmienky.
  • Párne číslo: n % 2 == 0.
  • Poradie elif rozhoduje – vykoná sa prvá splnená vetva.
