Číselné, znakové a logické premenné

1Typy premenných

Každá hodnota v Pythone má typ. Typ určuje, čo s hodnotou môžeš robiť: čísla sčítavať, texty spájať.

TypČo uchovávaPríklad
intcelé číslovek = 16
floatdesatinné čísloteplota = 21.5
strreťazec (text) v úvodzovkáchmeno = 'Ema'
boollogická hodnota True / Falsehotovo = True

Python nemá samostatný typ pre znak: znak je reťazec dĺžky 1. Typ zistíš funkciou type(). Premenná môže neskôr dostať hodnotu iného typu.

2Porovnania

Porovnanie vráti logickú hodnotu True alebo False. Pozor: = priraďuje, == porovnáva.

OperátorVýznam
==rovná sa
!=nerovná sa
< >menší, väčší
<= >=menší alebo rovný, väčší alebo rovný

Reťazce sa porovnávajú abecedne podľa kódov znakov – veľké písmená sú pred malými.

3Logické operátory

and (a zároveň) – pravda, ak sú pravdivé obe strany; or (alebo) – stačí jedna; not – obráti hodnotu.

ABA and BA or B
TrueTrueTrueTrue
TrueFalseFalseTrue
FalseFalseFalseFalse

Priorita: najprv not, potom and, nakoniec or.

4Prevody medzi typmi

Hodnotu jedného typu prevedieš na iný prevodnou funkciou:

FunkciaVýsledok
int(x)celé číslo (desatinnú časť odsekne)
float(x)desatinné číslo
str(x)reťazec
bool(x)0, 0.0 a '' sú False, všetko ostatné True

input() vracia vždy reťazec, preto s číslami treba int(input()). Písmená na číslo neprevedieš (ValueError), číslo a reťazec nespojíš (TypeError).

5Programy s typmi

Postup programu: vstup → prevod → výpočet → výstup.

Výsledok porovnania je typu bool, môžeš ho vypísať priamo, bez príkazu if: print(body >= 50) vypíše True alebo False.

Interval overíš dvoma porovnaniami spojenými and alebo zreťazeným porovnaním 1 <= z <= 5.

Dodrž tvar výstupu z ukážky – program sa kontroluje viacerými vstupmi.

💡 Vedel si? Typ bool je pomenovaný po anglickom matematikovi Georgeovi Booleovi (1815 – 1864). Jeho logická algebra s dvoma hodnotami je dnes základom každého počítača.

  • Typ zistíš funkciou type(); premenná môže neskôr dostať hodnotu iného typu.
  • Porovnania == != < > <= >= vracajú bool; = priraďuje, == porovnáva.
  • and – obe pravdivé, or – stačí jedna, not – obráti; priorita not → and → or.
  • Prevody int(), float(), str(), bool(); 0, 0.0 a '' sú False.
  • input() vracia reťazec → int(input()); chyby ValueError a TypeError.
  • Interval: z >= 1 and z <= 5, skrátene 1 <= z <= 5.
