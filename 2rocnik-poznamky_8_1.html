Statické a dynamické webové stránky, kód HTML, tvorba HTML dokumentu

1Statické a dynamické stránky

Webová stránka je dokument, ktorý prehliadač stiahne z webového servera protokolom HTTP(S) a vykreslí.

  • Statická stránka: hotové súbory HTML, CSS a obrázky. Server ich pošle bez zmeny, každý vidí to isté. Obsah mení autor úpravou súborov.
  • Dynamická stránka: server ju pri každej požiadavke poskladá programom (PHP, Python, Node.js) z databázy. Ukazuje obsah podľa používateľa (EduPage, e-shop, sociálne siete). Často beží na redakčnom systéme (WordPress).

Na strane prehliadača môže stránku oživiť JavaScript (napr. aj táto hodina), ale výsledkom je vždy HTML.

2Kód HTML

HTML (HyperText Markup Language) je značkovací jazyk. Značky (tagy) v lomených zátvorkách určujú, čo je nadpis, odsek, obrázok či odkaz.

  • Párová značka: <p>text</p>. Nepárová: <br>, <img>.
  • Atribút dopĺňa značku: <a href="https://gymrs.sk">, <img src="kocka.svg" alt="krajina">.
  • Dokument má hlavičku <head> (kódovanie, názov na karte) a telo <body> (čo vidíš).
  • Značky sa vnárajú správne: čo otvoríš posledné, zatvoríš prvé.

3Značky na vlastnej stránke

  • Nadpisy <h1> až <h6>, odsek <p>.
  • Zoznamy <ul>, <ol> a položky <li>.
  • Obrázok <img src alt>, odkaz <a href>.
  • Súbor ulož ako index.html.

4Ktorá značka

  • Nadpis → h1.
  • Odrážky → ul a li.
  • Odkaz → a href.
💡 Vedel si? Prvú webovú stránku zverejnil Tim Berners-Lee v CERN-e v roku 1991. Je online dodnes.
