Zápis algoritmov

1Jeden algoritmus, štyri zápisy

Ten istý postup sa dá zapísať rôznymi spôsobmi. Ktorý zvolíme, závisí od toho, kto ho bude čítať alebo vykonávať.

slovný zápisbežné vety; zrozumiteľný pre každého, pri dlhých postupoch neprehľadný
vývojový diagramgrafické značky spojené šípkami
pseudokódslová, ale usporiadané ako program
programpresné pravidlá programovacieho jazyka, napr. Python

Prvé tri zápisy sú pre ľudí, program je zápis pre počítač.

2Značky vývojového diagramu

Vývojový diagram je grafický zápis algoritmu. Každý druh kroku má svoju značku, diagram prečíta každý, kto značky pozná.

oválzačiatok / koniec – presne jeden začiatok, aspoň jeden koniec
rovnobežníkvstup / výstup: načítaj údaj, vypíš výsledok
obdĺžnikpríkaz, výpočet, napr. s ← s + 1
kosoštvorecrozhodovanie: otázka áno / nie, vychádzajú dve šípky
šípka (spojnica)ktorým smerom postup pokračuje

Diagram čítame zhora nadol po šípkach.

3Vývojový diagram a zvyšok po delení

Úloha: algoritmus načíta číslo n a vypíše, či je párne alebo nepárne. Číslo je párne, keď je zvyšok po delení dvoma rovný 0.

ZápisVýpočetVýsledok
7 mod 27 : 2 = 3, zvyšok 11
11 mod 311 : 3 = 3, zvyšok 22
8 mod 48 : 4 = 2, zvyšok 00

a mod b je zvyšok po delení čísla a číslom b. Keď je zvyšok 0, číslo a je deliteľné číslom b.

Rozhodovanie má dve vetvy, áno a nie; vykoná sa iba jedna z nich.

4Pseudokód a cyklus

Pseudokód vyzerá ako program, ale píšeme ho bežnými slovami:

ak – tak – inakvetvenie: vykoná sa jedna z dvoch vetiev
kým – opakujcyklus: opakuje sa, kým platí podmienka
s ← 0do premennej s ulož 0; s ← s + i zväčší s o i
odsadenieriadky, ktoré patria do cyklu alebo vetvy

Python je prísnejší: kľúčové slová sú anglické a každý znak musí byť na svojom mieste.

5Python: range, for, if

PythonČo urobí
range(n)čísla 0, 1, …, n − 1
range(a, b)čísla a, a + 1, …, b − 1
for i in …:zopakuje odsadené riadky pre každé číslo
if … elsevykoná iba jednu z dvoch vetiev
% / == / =zvyšok po delení / porovnanie / priradenie

Program čítaj riadok po riadku a zapisuj si hodnoty premenných.

💡 Vedel si? Značky vývojových diagramov určuje medzinárodná norma ISO 5807. Preto diagram nakreslený na Slovensku prečíta programátor v Japonsku aj v Brazílii.

📌 Zapamätaj si

  • Algoritmus zapíšeme slovne, diagramom, pseudokódom alebo programom.
  • Ovál = začiatok/koniec, rovnobežník = vstup/výstup, obdĺžnik = príkaz, kosoštvorec = rozhodovanie.
  • a mod b = zvyšok po delení; zvyšok 0 = deliteľné.
  • ak – tak – inak = vetvenie, kým – opakuj = cyklus, vnútro odsadíme.
  • range(a, b) dá čísla a až b − 1.
