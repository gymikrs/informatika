Vznik a história internetu

1Časová os internetu

RokČo sa stalo
1969ARPANET – v USA prepojili prvé 4 počítače
1971prvý e-mail – ARPANET mal len 2 roky
1983TCP/IP – spoločný jazyk sietí = narodeniny internetu
1991WWW (web) – Tim Berners-Lee, CERN (Švajčiarsko)
1998Google – vyhľadávač
2005YouTube – videá na webe

2Internet ≠ web

Internet je celosvetová sieť prepojených počítačov. Predstav si ho ako cesty, ktoré spájajú mestá.

Po cestách jazdia služby internetu (vozidlá):

  • web (WWW) – webové stránky
  • e-mail – elektronická pošta
  • videohovory, prenos súborov

Web je iba jedna zo služieb internetu.

3ISP – poskytovateľ internetu

ISP (Internet Service Provider) je firma, ktorá ti dodáva internet, napr. Slovak Telekom, Orange, O2.

Platí sa jej mesačne, ako za vodu či elektrinu.

Cesta tvojej požiadavky k webovej stránke:
počítač → router → ISP → internet → server

4URL – adresa na internete

URL je adresa stránky alebo súboru na internete.

Funguje ako adresa na balíku: ako doručiť, do ktorého domu a do ktorej izby.

https://sk.wikipedia.org/wiki/Internet

ČasťPríkladVýznam
protokolhttps://ako doručiť
doménask.wikipedia.org„dom“ = server
cesta/wiki/Internet„izba“ = súbor

5HTTP a HTTPS

HTTP – pravidlá (protokol), podľa ktorých si prehliadač a server posielajú webové stránky.

HTTPS – S = secure (zabezpečený): všetko sa posiela zašifrované.

HTTPpohľadnica – prečíta ju každý
HTTPSzalepená obálka

🔒 Zámok pred adresou = HTTPS. Heslá zadávaj iba tam!

6FTP – prenos súborov

FTP (File Transfer Protocol) slúži na prenos súborov medzi počítačom a serverom, napr. keď tvorca webu nahráva stránku na server.

UPLOADnahrať: počítač → server
DOWNLOADstiahnuť: server → počítač
💡 Vedel si? Prvá správa poslaná cez ARPANET v roku 1969 mala byť slovo LOGIN. Počítač však spadol po prvých dvoch písmenách, takže prvá správa bola iba „LO“.

📌 Zapamätaj si

  • Internet vznikol z ARPANETu (1969), narodeniny má v roku 1983 (TCP/IP).
  • Web (WWW) vytvoril Tim Berners-Lee v roku 1991, internet je o viac ako 20 rokov starší ako web.
  • ISP dodáva internet.
  • URL = protokol + doména + cesta.
  • HTTPS = zašifrované · FTP = prenos súborov.
