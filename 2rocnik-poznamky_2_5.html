OS Linux – distribúcie, popis prostredia

1Linux a distribúcie

Linux je jadro operačného systému, ktoré v roku 1991 zverejnil fínsky študent Linus Torvalds. Je open source (licencia GNU GPL): zdrojový kód je verejný a zadarmo.

Samotné jadro však nestačí. Distribúcia je celok: jadro + systémové nástroje + grafické prostredie + aplikácie + správca balíkov na inštaláciu programov.

Známe distribúcie: Ubuntu a Linux Mint (pre začiatočníkov), Debian, Fedora, Arch (pokročilí, servery), Raspberry Pi OS, Kali, SteamOS.

Linux beží na väčšine serverov a superpočítačov a jadro Linux používa aj Android. Vyskúšať ho môžeš z Live USB bez inštalácie.

2Prostredie Ubuntu

Linux má viac grafických prostredí. Prostredie určuje, ako vyzerá plocha, okná a ponuky, a dá sa aj vymeniť.

Ubuntu s GNOME má hore lištu, vľavo dok a tlačidlo Aktivity.

3Súborový systém

Linux nemá disky C: a D:. Všetko je v jednom strome, ktorý začína koreňom /. Ďalšie disky a USB sa pripájajú do priečinkov (napr. /media).

AdresárČo obsahuje
/homedomovské priečinky používateľov (skratka ~)
/etcnastavenia systému
/bin, /usrprogramy
/tmpdočasné súbory
/mediapripojené USB kľúče a disky
/devzariadenia

Cesty sa oddeľujú lomkou / a Linux rozlišuje veľké a malé písmená. Správca systému sa volá root, bežný používateľ získa jeho práva dočasne cez sudo.

4Terminál

Terminál (príkazový riadok) je najsilnejší nástroj Linuxu. Príkazy sa doň píšu a potvrdzujú klávesom Enter.

cp, mv, rmkopírovanie, presun, mazanie

5Inštalácia softvéru

Vo Windows si program často stiahneš z webu ako setup.exe. V Linuxe je to inak: programy sú zbalené v balíkoch a ležia v repozitári, overenom úložisku distribúcie. Inštaláciu robí správca balíkov.

DistribúciaSprávca balíkov
Debian, Ubuntu, Mintapt (balíky .deb)
Fedoradnf (balíky .rpm)
Arch Linuxpacman
PríkazČo urobí
sudo apt updateobnoví zoznamy balíkov
sudo apt upgradenainštaluje nové verzie programov
sudo apt install vlcnainštaluje program vlc
sudo apt remove vlcprogram odstráni

Bez terminálu poslúži Centrum aplikácií. Univerzálne balíky Snap a Flatpak (obchod Flathub) fungujú vo viacerých distribúciách.

💡 Vedel si? Linus Torvalds v roku 1991 napísal, že jeho systém je „len hobby, nebude veľký a profesionálny“. Dnes na Linuxe beží väčšina internetu aj všetkých 500 najvýkonnejších superpočítačov sveta.
