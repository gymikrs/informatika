Internet, jeho služby a web

Čo je internet a ako funguje

Internet je celosvetová sieť navzájom prepojených počítačových sietí, ktoré si vymieňajú údaje pomocou spoločných pravidiel – protokolov TCP/IP. Nemá jedného vlastníka ani centrálny počítač.

Základné princípy

  • Prepájanie paketov – údaje sa rozdelia na malé časti (pakety). Každý paket nesie adresu odosielateľa a príjemcu a môže ísť inou cestou. U príjemcu sa pakety poskladajú do pôvodného poradia.
  • IP adresy – každé zariadenie v sieti má jednoznačnú adresu, podľa ktorej ho pakety nájdu.
  • Smerovače (routery) – na každej križovatke sietí rozhodnú, kam paket poslať ďalej.
  • Protokoly – IP doručuje pakety, TCP kontroluje, či prišli všetky a v poriadku, ďalšie protokoly (HTTP, SMTP, DNS) určujú pravidlá jednotlivých služieb.
  • Decentralizácia – ak niektorá cesta vypadne, pakety idú inou. Internet vznikol z vojenskej siete ARPANET (1969) práve s cieľom odolnosti.

Do internetu nás pripája poskytovateľ internetu (ISP) – napr. cez optiku, DSL, mobilnú sieť alebo satelit.

Internet ≠ web. Internet je infraštruktúra – fyzická sieť prepojených počítačov, káblov a smerovačov. Web (WWW) je len jedna zo služieb, ktoré internet poskytuje – systém webových stránok prepojených hypertextovými odkazmi. Web vymyslel Tim Berners-Lee v CERN-e v roku 1989, internet existoval už predtým. E-mail či online hry fungujú cez internet, ale nie sú súčasťou webu.

Webová stránka, server a prehliadač

Webová stránka, webový server a prehliadač

  • Webová stránka – dokument zapísaný v jazyku HTML, ktorý môže obsahovať text, obrázky, video a odkazy na ďalšie stránky. Skupina súvisiacich stránok pod jednou doménou je webová lokalita (web, site).
  • Webový server – počítač s programom (Apache, nginx), ktorý uchováva stránky a na požiadanie ich posiela. Beží nepretržite a je dostupný cez internet.
  • Webový prehliadač – program na strane používateľa (Chrome, Firefox, Edge, Safari), ktorý pošle požiadavku, prijme stránku, vykreslí ju a umožní klikať na odkazy.

Komunikácia klient – server

Prehliadač je klient, ktorý žiada, web je na serveri, ktorý odpovedá. Komunikácia prebieha protokolom HTTP/HTTPS po schéme požiadavka – odpoveď:

  1. DNS preloží doménové meno na IP adresu servera.
  2. Prehliadač pošle požiadavku (napr. GET /index.html).
  3. Server nájde alebo vytvorí stránku a pošle odpoveď so stavovým kódom (200 OK, 404 Nenájdené, 500 chyba servera) a obsahom.
  4. Prehliadač stránku vykreslí a podľa potreby si vyžiada ďalšie súbory (obrázky, CSS, JS).

Pri HTTPS je komunikácia šifrovaná (TLS) a server sa preukazuje certifikátom – v prehliadači vidíme zámok.

Responzívny dizajn a breakpoint

Responzívny dizajn znamená, že sa webová stránka automaticky prispôsobí veľkosti obrazovky – na počítači sa obsah zobrazí vo viacerých stĺpcoch, na tablete v menej, na mobile pod sebou, s väčšími tlačidlami a skrytou ponukou (ikona ☰).

Prečo je dôležitý: väčšina ľudí prezerá web na mobile, nikto nechce približovať a posúvať stránku do strán, Google uprednostňuje vo vyhľadávaní stránky vhodné pre mobily, netreba robiť zvlášť mobilnú verziu.

Breakpoint (bod zlomu) je šírka obrazovky, pri ktorej sa rozloženie stránky zmení. V CSS sa zapisuje pomocou media queries:

@media (max-width: 768px) {     /* tablet a menej */
  .stlpce { flex-direction: column; }
}

Bežné breakpointy: približne 480 px (mobil), 768 px (tablet), 1024 px (malý notebook), 1280 px a viac (počítač). Aj táto stránka má breakpoint – na mobile sa obrázky presunú pod text.
