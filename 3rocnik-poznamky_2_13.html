Premenné, volanie premennej, výmena obsahu dvoch premenných

1Premenná a jej meno

Premenná je meno, ktoré odkazuje na hodnotu v pamäti. Vzniká priradením meno = hodnota – znak = neznamená „rovná sa“, ale „ulož“.

PravidloPodrobnosti
začiatokpísmeno alebo _
ďalšie znakypísmená, číslice a _, bez medzier a pomlčiek
zakázanékľúčové slová (if, for, while…)
veľkosť písmenBody a body sú dve rôzne premenné

Používame výstižné mená v štýle snake_case, napr. dlzka_strany.

2Volanie a zmena premennej

Keď meno premennej použijeme vo výraze alebo v print, premennú voláme: Python dosadí jej aktuálnu hodnotu.

Premennú, ktorej sme ešte nič nepriradili, zavolať nemôžeme – Python ohlási NameError. Nové priradenie starú hodnotu prepíše.

ZápisVýznam
x = x + 1vezme starú hodnotu, pripočíta 1 a uloží späť
x += 1skrátený zápis toho istého
a, b, c = 1, 2, 3viac premenných naraz

3Krokovanie programu

Krokovanie (trasovanie) znamená prechádzať program riadok po riadku a zapisovať si hodnoty všetkých premenných do tabuľky.

Pri každom priradení najprv vypočítaj pravú stranu so súčasnými hodnotami, až potom výsledok ulož do premennej vľavo.

Výsledok najprv odhadni na papieri, potom ho over. Krokovanie pomáha nájsť chyby v programe.

4Výmena obsahu dvoch premenných

Dva poháre – v jednom džús, v druhom mlieko. Na výmenu potrebuješ tretí, prázdny pohár. V programe je to pomocná premenná:

pom = a a = b b = pom

Chybná výmena a = b, b = a pôvodnú hodnotu a stratí.

Paralelné priradenie a, b = b, a: Python najprv vyhodnotí celú pravú stranu (obe staré hodnoty), až potom priraďuje.

5Výpis a spôsoby výmeny

Na výpis sa hodí f-reťazec: písmeno f pred úvodzovkou povie Pythonu, aby mená v zložených zátvorkách nahradil hodnotami.

VýmenaKedy
pomocná premennávždy, 3 príkazy
paralelné priradeniejedným príkazom, aj pre viac premenných
súčet a rozdieliba pre čísla: a = a + b, b = a − b, a = a − b

Program over viacerými vstupmi a dodrž tvar výstupu z ukážky.

💡 Vedel si? Programátori poznajú aj trik s operáciou XOR (v Pythone ^): a ^= b, b ^= a, a ^= b vymení dve celé čísla bez pomocnej premennej. Kedysi sa tak šetrila pamäť.

📌 Zapamätaj si

  • Premenná = meno, ktoré odkazuje na hodnotu; vzniká priradením meno = hodnota (= znamená „ulož“).
  • Meno: začína písmenom alebo _, bez medzier a pomlčiek, nie kľúčové slovo; Python rozlišuje veľké a malé písmená.
  • Volanie = použitie mena, Python dosadí aktuálnu hodnotu; nepriradená premenná → NameError.
  • x = x + 1 (skrátene x += 1) – najprv sa vypočíta pravá strana, potom sa uloží vľavo.
  • Krokovanie = prechádzanie programu riadok po riadku s tabuľkou hodnôt premenných.
  • Výmena: pom = a, a = b, b = pom alebo a, b = b, a.
  • f-reťazec: print(f'x = {x}') nahradí {x} hodnotou.
