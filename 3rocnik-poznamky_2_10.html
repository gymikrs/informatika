Premenné a náhodné hodnoty

1Premenné v kreslení

Premenná je pomenované miesto v pamäti s hodnotou: x = 50. Kde napíšeš meno premennej, Python použije jej uloženú hodnotu.

VýrazVýznam
x + asúčet hodnôt premenných
y - 10rozdiel
a // 2celočíselné delenie
x = 50 y = 60 a = 120 canvas.create_rectangle(x, y, x + a, y + a, fill='orange')

x = x + a + 20 vezme starú hodnotu x, pripočíta a + 20 a výsledok uloží späť do x.

2Výpočty zo stredu a polomeru

Kruh je pohodlnejšie zadať stredom (sx, sy) a polomerom r. Rohy vypočíta Python:

canvas.create_oval(sx - r, sy - r, sx + r, sy + r)
ZmenímeČo sa stane
r, napr. r = r - 40rovnaký príkaz nakreslí ďalší kruh s rovnakým stredom
sx alebo sykruh sa posunie

Kruhy tesne vedľa seba: stred posunieme o priemer 2 · r.

3Náhodné hodnoty

Modul random generuje náhodné hodnoty; na začiatok programu import random.

FunkciaVráti
random.randint(a, b)celé číslo od a do b vrátane
random.randrange(n)celé číslo od 0 do n − 1
random.choice(zoznam)náhodný prvok zoznamu
import random random.randint(1, 6) # hod kockou random.choice(['red', 'blue'])

Aby bol kruh celý v ploche, stred vyberaj s odstupom polomeru od okrajov.

4Premenné a náhoda spolu

FunkciaRozsah
randint(a, b)a až b vrátane
randrange(n)0 až n − 1
choice(zoznam)jeden prvok zoznamu

Náhodné súradnice voľ tak, aby tvar nevyšiel mimo plochy. Nezabudni na import random.

💡 Vedel si? Počítač náhodu iba napodobňuje: modul random počíta pseudonáhodné čísla zo štartovacej hodnoty (seed). Po random.seed(42) dostaneš pri každom spustení rovnakú postupnosť.

📌 Zapamätaj si

  • Premenná = pomenovaná hodnota; x = x + a vezme starú hodnotu a uloží novú.
  • Kruh: create_oval(sx − r, sy − r, sx + r, sy + r); zmenou r sústredné kruhy.
  • import random; randint(a, b) a až b vrátane, randrange(n) 0 až n − 1.
  • choice(zoznam) vyberie náhodný prvok.
  • Náhodný stred vyberaj s odstupom polomeru od okrajov.
